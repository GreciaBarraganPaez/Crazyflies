# Preserved formation source snapshot — 3 November 2026

Source snapshot of the existing formation engine, tests, configuration and
launchers, captured during the optional Snake-mode addition. Normal launcher
defaults still select the existing four formations. Launchers include the
optional Snake selector; Snake-specific source files are outside this snapshot.

This is not a complete repository/runtime backup. Existing model assets, data,
ROS installation and ML source remain in the original project and were not
changed. `manifest.json` records original project-relative paths and SHA-256
checksums. Restore source files only to their matching original paths, after
stopping the project. The archive is excluded from active test discovery.
