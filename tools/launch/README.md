# Launcher internals and optional shortcuts

Use `Start-SwarmGesture.cmd` in the project root for normal formations, or
`SwarmGesture-Tools.cmd` for the optional mode/restart/recovery menu.

The small CMD files here are convenience aliases for
`Start-SwarmGesture.ps1`. They are kept for direct access, but you do not need
them for normal startup. They resolve the project root before running.

See [the file guide](../../docs/project-map.md) for each shortcut's purpose and
[launching instructions](../../docs/launching.md) for detailed controls.
