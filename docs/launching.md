# Launching SwarmGesture

Start-SwarmGesture.cmd opens ROS/RViz, the gesture bridge, colored markers and
the Windows webcam. SwarmGesture-Tools.cmd provides physics, bridge restart and
confirmed WSL recovery. Land and stop the four programs before a full restart.
For only a Python controller edit, land and stop the old bridge, then use the
bridge restart option. Manual arming (a + Enter) is required before takeoff.
E enables webcam transmission. Palm/X requests grid-first landing; Q quits.

After takeoff use heart, sine, spiral, moon, helix or demo in the bridge terminal.
A saved 3D Helix RViz view reveals depth; Front formations restores the front
camera. The six trained hand labels are unchanged. Only ideal simulation has
been validated; these are not hardware flight instructions.
